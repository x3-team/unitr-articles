Резервирование питания: схемы 2N и N+1 простыми словами

15.07.2026 · Сергей Никитин

Резервирование — способ сохранить работу оборудования при отказе одного из элементов системы питания.

N — без резерва

Количество элементов ровно то, которое нужно для работы. Отказ любого из них — остановка.

N+1

Один дополнительный элемент. Позволяет пережить отказ одного ИБП или проводить обслуживание без остановки.

2N

Полное дублирование: две независимые линии питания от ввода до PDU. Каждый сервер подключается к обеим линиям двумя блоками питания.

Что выбрать

Для корпоративной серверной обычно достаточно N+1. Схема 2N оправдана для критичных систем с требованиями к доступности 99,99 % и выше.
