# WordPress manage.unitr.ru: настройка раздела «Статьи» через админку (без SSH)

Выполняется под администратором (MainAdmin). Занимает 15–20 минут. Можно делать до выкладки фронта: на текущий сайт
это не влияет — плагин не меняет существующие записи, страницы, меню и адреса записей вне рубрики «Полезные статьи».

Плагин: https://github.com/x3-team/unitr-articles/releases → последний релиз `wp-v…` → `unitr-articles-wp-plugin.zip`.
Проверен в WordPress 6.5 (`tests/wp/run-wp-smoke.sh`); требования — WordPress ≥ 6.0, PHP ≥ 7.4.

## 0. Перед началом

- [ ] **Резервная копия.** В панели Reg.ru (Сайты → manage.unitr.ru → Резервные копии) или плагином резервного
      копирования, если он стоит. Минимум — «Инструменты → Экспорт → Все данные».
- [ ] «Консоль → Обновления»: версии WordPress и PHP (внизу «Консоль → Здоровье сайта → Информация»).
      Нужны WordPress ≥ 6.0 и PHP ≥ 7.4. Обновлять ядро сейчас **не нужно**.

## 1. Плагины, которые уже должны быть

«Плагины → Установленные»:

- [ ] **WPGraphQL** — активен (обязательно; через него фронт получает статьи). Версия ≥ 1.14.
      Если нет — «Плагины → Добавить новый» → поиск «WPGraphQL» → Установить → Активировать.
- [ ] ACF / ACF PRO — если есть, хорошо: SEO-поля появятся группой ACF. Если нет — плагин покажет свой блок полей.
- [ ] WPGraphQL for ACF — по желанию (поля и так доступны фронту через `unitrSeo`).
- [ ] Записать, какие ещё стоят SEO-плагины (Yoast SEO, Rank Math) и Cyr-To-Lat — с ними плагин раздела совместим.

## 2. Установка плагина раздела

- [ ] «Плагины → Добавить новый → Загрузить плагин» → `unitr-articles-wp-plugin.zip` → «Установить» → «Активировать».
- [ ] В списке плагинов у «Юнит-Ресурс — раздел «Статьи»» есть ссылки «Настройки» и «Проверка».

При активации плагин сам создаёт рубрику «Полезные статьи» (`poleznye-stati`), если её нет, и сохраняет настройки
по умолчанию (10 анонсов, адрес сайта https://unitr.ru, случайный секрет вебхука).

## 3. Рубрика

«Записи → Рубрики»:

- [ ] Есть рубрика «Полезные статьи» с ярлыком **`poleznye-stati`** (ровно так, латиницей).
      Если рубрика уже была с другим ярлыком — исправить ярлык на `poleznye-stati`.
- [ ] Подрубрики (если нужны) — дочерние к «Полезные статьи», ярлыки латиницей. Они появятся на сайте как
      `/articles/category/<ярлык>/` и в sitemap автоматически.

## 4. Настройки раздела

«Настройки → Раздел «Статьи»»:

- [ ] «Анонсов на странице» = 10 (здесь же Заказчик потом меняет количество без программиста).
- [ ] «Адрес сайта» = `https://unitr.ru`.
- [ ] «Секрет вебхука» — заполнен (сгенерирован автоматически). **Скопировать** его в защищённое место: это значение
      `REVALIDATE_SECRET` на сервере сайта (вариант А). В варианте Б (статическая выкладка) поле очистить.
- [ ] «Репозиторий GitHub» и «Токен GitHub» — только для варианта Б, заполняются в день выкладки (RUNBOOK, Б4).
- [ ] «Ссылки «Просмотреть»» — **оставить выключенным** до запуска раздела на unitr.ru, потом включить
      (кнопка «Просмотреть» у статьи будет открывать `unitr.ru/articles/<адрес>/`).

## 5. Пароль приложения для сайта

Сайт читает статьи от имени пользователя WordPress с минимальными правами.

- [ ] «Пользователи → Добавить нового»: логин `unitr-site`, роль **Редактор** (или существующий редактор).
- [ ] Открыть профиль этого пользователя → блок «Пароли приложений» → имя `unitr.ru articles` → «Добавить».
- [ ] Скопировать пароль (показывается один раз) и передать по защищённому каналу. На сервер он попадает как
      `WP_GRAPHQL_TOKEN=unitr-site:<пароль приложения>` и больше нигде не хранится — ни в коде, ни в браузере.

Если блока «Пароли приложений» нет — их отключил плагин безопасности (Wordfence, iThemes и т.п.) или сайт открыт
не по HTTPS; включить в настройках этого плагина.

## 6. Статьи

Для каждой статьи рубрики (можно постепенно, сайт покажет и неполные):

- [ ] Рубрика «Полезные статьи» (или её подрубрика).
- [ ] **Изображение записи** (обложка) — горизонтальное, лучше 1200×630 и больше: анонс, Open Graph, Schema.org.
- [ ] **Отрывок** (excerpt) — 1–2 предложения для анонса в списке. Если блок не виден: в редакторе
      «⋮ → Настройки → Панели» → включить «Отрывок».
- [ ] **SEO title / Meta description** — блок «SEO для раздела «Статьи»» в боковой панели редактора (или группа ACF с тем же названием).
      Пусто — берутся Yoast/Rank Math, затем заголовок и отрывок.
- [ ] Подзаголовки внутри текста — блоками «Заголовок» уровня H2/H3 (не жирным текстом).
- [ ] Адрес (ярлык) — латиницей. Кириллический адрес плагин переводит в латиницу при сохранении статьи рубрики.

Сводка по незаполненным полям — «Записи → Все записи», колонка «Раздел «Статьи»», и страница проверки (п. 8).

## 7. Меню основного сайта (ТЗ, задача 2)

- [ ] «Внешний вид → Меню» (или «Внешний вид → Редактор → Навигация» у блочной темы): если там есть меню шапки
      сайта unitr.ru с пунктами «Каталог» и «Конфигураторы» — добавить «Произвольная ссылка»:
      текст **Статьи**, URL **`/articles/`**, поставить после «Конфигураторы», «Сохранить меню».
- [ ] Если такого меню в WordPress нет — шапка зашита в код основного сайта; пункт добавляется при выкладке
      (RUNBOOK, шаг 5). Отметить это в отчёте.

## 8. Проверка

«Инструменты → Проверка раздела «Статьи»»:

- [ ] WPGraphQL — ✅; рубрика — ✅; «GraphQL-запрос фронтенда» — ✅ (выполняется тот же GraphQL-запрос, что делает сайт).
- [ ] «Обложки, анонсы, SEO» — список статей, где чего-то не хватает (⚠️ не блокирует запуск).
- [ ] Кнопка «Отправить тестовый вебхук» — нажимать **после** выкладки фронта (до неё ответит текущий сайт).

Проверка GraphQL снаружи (с любого компьютера, подставить логин и пароль приложения из п. 5):

```bash
curl -s -u 'unitr-site:xxxx xxxx xxxx xxxx xxxx xxxx' https://manage.unitr.ru/graphql \
  -H 'Content-Type: application/json' \
  -d '{"query":"{ unitrArticlesSettings { perPage category } posts(first: 3, where: {categoryName: \"poleznye-stati\"}) { nodes { slug title unitrSeo { title description } featuredImage { node { sourceUrl } } } } }"}'
```

Ожидается JSON с `perPage: 10`, `category: "poleznye-stati"` и статьями (или пустым списком, если статей ещё нет).

## Что передать для выкладки

1. Секрет вебхука (п. 4) — для варианта А.
2. Логин и пароль приложения (п. 5).
3. Есть ли меню шапки в WordPress (п. 7).
4. Результат страницы проверки (скриншот).
